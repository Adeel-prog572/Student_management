# Student Management System

A simple Student Management System built with PHP, MySQL, HTML, CSS, and JavaScript.

## Features

- Add new students
- Display student records
- Delete students
- MySQL database integration
- Responsive and clean interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Database

Database name:

`student_management`

Table:

`students`
